Sistema de Notas em Python 🐍

Projeto desenvolvido com Python para realizar o cadastro e a consulta de alunos, calcular médias e verificar situações acadêmicas.

Funcionalidades

- Cadastro de múltiplos alunos.
- Registro de quatro notas bimestrais.
- Validação das notas (0 a 10).
- Cálculo automático da média.
- Verificação da situação do aluno:
  - Aprovado: média maior ou igual a 7.
  - Recuperação: média maior ou igual a 5.
  - Reprovado: média menor que 5.
- Pesquisa de alunos pelo nome.

Feito em: Python 3

Como executar

1. Tenha o Python 3 instalado.
2. Clone ou baixe este repositório.
3. Abra o terminal na pasta do projeto.
4. Execute o comando:

python sistemas_notas.py
